ఎలా పనిచేస్తుంది? / How it works

మూడు steps — customer కి, మీకు ఇద్దరికీ సులభం.

1

Upload

Customer షాప్ దగ్గర QR scan చేసి PDF / ఫోటో upload చేస్తాడు — తన ఫోన్ browser లోనే, app అవసరం లేదు.

2

Pay

UPI తో pay చేస్తే వెంటనే print కి ready; Cash అయితే మీ approval తర్వాత. డబ్బు నేరుగా మీ UPI account కి.

3

Token & Collect

Token number వస్తుంది; print అయ్యాక customer token చూపించి collect చేసుకుంటాడు. Queue లో గందరగోళం లేదు.

Features / ఫీచర్లు

షాప్‌కి కావాల్సినవన్నీ — ఒకే software లో.

🎫 Token System

ప్రతి order కి token number — queue లో గందరగోళం లేదు, customer status check చేసుకోవచ్చు.

💳 UPI + Cash

UPI tap-to-pay; Cash కి owner approval. UPI paid orders auto-print అవుతాయి.

🖨️ Multi-Machine

2–3 printers ఉంటే Auto — ఖాళీగా ఉన్న machine కి order వెళ్తుంది. Print-next బటన్‌తో వరుసగా print చేయవచ్చు.

🧾 Bills & Credit

Customer bills, office monthly billing, credit accounts — నెల చివర ఒకే bill.

🔄 Silent Updates

కొత్త version వస్తే అదే install అవుతుంది — మీరేం చేయనక్కర్లేదు.

🌐 తెలుగు + English

Customer page, owner dashboard — రెండు భాషల్లో. త్వరలో Tamil, Hindi కూడా.
